# Waldo

> Waldo is a no-code mobile test automation platform for iOS and Android. Teams create, run, and maintain reliable end-to-end tests on a cloud of virtual devices (iOS simulators and Android emulators) with zero device setup. The Scripting (Core) API is a W3C WebDriver + Appium-compatible endpoint at core.waldo.com for driving native, hybrid, and mobile-web apps programmatically. Waldo was acquired by Tricentis in July 2023.

## APIs
- [Waldo Scripting (Core) API — Introduction](https://docs.waldo.com/reference/introduction): W3C WebDriver + Appium-compatible endpoint (core.waldo.com) to create sessions on cloud devices and drive apps.
- [Authentication](https://docs.waldo.com/reference/authentication): API-token authentication (user-scoped and CI/application-scoped tokens).
